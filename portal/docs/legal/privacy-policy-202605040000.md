# WOODGIT 隐私政策

> **ACTIVE** - 最后更新：2026年4月30日

WOODGIT OpenPlatform Privacy Policy

欢迎您使用 WOODGIT（以下简称"本服务"或"本平台"）提供的服务。本《WOODGIT 隐私政策》（以下简称"本政策"）旨在清楚说明我们如何收集、使用、披露和保护您的个人信息，以及您拥有的权利和可以帮助您做出适当选择。您的隐私对我们很重要。请花时间了解并熟悉本政策和做法。

## 关键要点

- **数据最小化**：我们坚持最小必要原则，仅收集提供服务所需的信息
- **安全保护**：采用行业领先的加密技术和安全措施保护您的数据
- **透明度**：我们不会出售您的 API 业务数据，不用于模型训练
- **跨境传输**：使用全球云基础设施，相关信息可能跨境存储

## 1. 我们收集哪些信息

### 1.1 您提供的信息

**账户信息**
您在注册和使用账户时提供的信息，如用户名、电话号码、头像、电子邮件地址和账户凭证。此信息用于创建和管理您的账户，确保您可以顺利访问和使用我们的服务。
- 邮箱
- 密码凭证
- 账号标识符

**用户内容**
您在使用我们的产品和服务时输入和生成的提示、文本、图像、视频、文件和其他内容。此信息帮助我们优化模型并了解您的需求和偏好，以便我们为您提供更准确的服务和支持。

**账单与交易信息**
为提供充值、结算、对账、开具发票/收据及满足法定义务，我们可能收集：
- 订单信息：订单号、金额、币种、支付状态
- 发票信息：开票抬头、账单地址、联系方式
- 增值税发票信息（如适用）：企业名称、纳税人识别号等

### 1.2 自动收集的信息

当您访问、使用或与本服务交互时，我们可能会自动接收以下信息：
- 日志数据：浏览器或设备在使用服务时自动发送的信息
- 设备和用法信息：设备型号、操作系统版本、唯一设备标识符、IP 地址、浏览器类型等
- Cookies 和类似技术：用于了解您的使用模式并提供更个性化的服务

### 1.3 从第三方接收的信息

我们可能从其他来源接收本政策中描述的信息，例如：
- 如果您选择使用 Google 等第三方服务注册或登录，我们可能会从该服务收集信息
- 我们可能从可信合作伙伴接收信息，以防止欺诈、滥用和其他安全威胁
- 我们可能通过互联网来源获取公开可用信息，以开发支持我们服务的模型

## 2. 我们如何使用您的信息

我们使用您的信息来提供、维护、改进和开发服务，包括以下目的：

- **提供服务**：创建和管理您的账户，提供无缝便捷的登录体验，使您能够与服务交互。
- **改进和开发服务**：分析您如何使用服务以识别改进领域、开发新功能并增强整体用户体验。
- **与您沟通**：通知您服务变更、提供客户支持或向您发送其他服务相关消息。
- **确保安全**：检测和防止欺诈活动、滥用和其他安全威胁，维护平台的完整性和稳定性。

**重要说明**：我们不提供、也不开展利用用户业务数据进行模型训练、微调或蒸馏的服务，亦不会出售您的 API 业务数据。当您调用第三方模型能力时，相关数据将被发送至第三方服务提供商处理；第三方的数据处理规则以其自身政策为准。

## 3. 我们如何共享您的信息

我们可能在以下情况下共享您的信息：

- **服务提供商**：我们聘请服务提供商帮助我们提供、支持和开发服务并了解服务的使用方式。这些提供商包括托管服务、客户服务供应商、云服务、支付处理商等。
- **关联公司**：我们可能与我们的关联公司共享您的信息，确保他们以与本隐私政策一致的方式处理您的信息。
- **法律义务**：如果我们真诚地认为有必要，我们可能与政府当局或其他第三方共享您的信息：遵守适用法律、法律程序或政府请求；保护我们、用户和公众的权利、财产和安全等。

## 4. 您的权利和选择

您有权访问、更正或更新、转移、删除您的个人信息，以及限制我们如何处理、撤回同意等。

- **访问权**：请求确认我们是否处理您的个人数据并获取副本
- **更正权**：请求更正不准确的个人信息
- **删除权**：请求删除您的个人信息
- **撤回同意权**：在基于同意处理时随时撤回同意

如果您无法通过上述方法行使您的权利，请通过 support@example.com 提交您的请求。

## 5. 信息安全

我们充分意识到您的个人信息的安全性和保密性对您至关重要。我们将采取合理的技术和组织措施保护您的个人信息：

- **数据加密**：使用行业领先的加密算法加密用户个人信息
- **系统安全**：定期进行安全检查和漏洞修补
- **访问控制**：严格限制员工访问用户数据，仅特定员工在必要时访问
- **数据备份**：定期备份并存储在不同物理位置

请注意，由于技术和管理手段的限制，虽然我们已采取上述措施并尽一切努力提高安全水平，但我们不能保证绝对安全。因此，您应特别谨慎地决定向我们发送哪些信息。

## 6. 数据保留

我们在必要的时间内存储您的信息以提供服务、履行本政策中概述的目的和其他合法商业目的（如服务改进、解决争议、安全或安全）、遵守法律义务。

保留期限因信息类型、敏感性和法律要求等因素而异。例如，账户、输入和支付信息在您的账户活跃期间保留。违规相关信息保留到违规解决为止。

您的个人信息可能被传输并存储在您居住国以外的服务器上。我们将收集的信息存储在位于新加坡的安全服务器中。

## 7. 儿童隐私

我们的服务不针对或意图用于 18 岁以下的儿童。如果您有理由相信 14 岁以下的儿童通过服务向我们提供了信息，请联系 support@example.com。我们将调查任何通知，并在适当情况下及时删除信息。

## 8. 隐私政策更新

我们可能根据需要不时更新本政策。当我们这样做时，我们将在此页面发布更新版本和生效日期，或通过适用法律要求的任何其他通知方式提供。我们建议您每次访问服务时查看更新的政策，以了解我们的最新做法。
