# WOODGIT 充值与支付条款

> **ACTIVE** - 最后更新：2026年4月30日

WOODGIT Payment Terms

欢迎使用 WOODGIT 充值与支付服务。在使用充值和支付功能前，请您仔细阅读本条款。充值即表示您同意本条款的约束。

## 1. 充值说明

### 1.1 充值性质

- 本平台采用**预充值消费模式**，您需要预先充值到账户余额后方可使用 API 服务。
- 充值金额将计入您的账户余额，用于抵扣 API 调用产生的费用。
- 账户余额为虚拟货币单位（人民币），仅可用于本平台 API 服务消费，不具有现金价值。

### 1.2 充值金额

- 最低充值金额为 **¥10**。
- 充值金额无上限，但单笔交易金额受支付渠道限制。
- 充值金额不支持部分充值，须为支付渠道支持的金额。

### 1.3 充值渠道

我们支持以下充值方式：
- **支付宝**：即时到账
- **微信支付**：即时到账
- **银行卡**：即时到账（部分银行可能存在延迟）

具体可用渠道以充值页面实际展示为准。

## 2. 计费方式

### 2.1 计费规则

- 本平台按 **Token 用量** 计费，根据不同模型和请求类型（输入/输出）分别计价。
- 每次请求的 Token 用量以上游服务提供商返回的用量数据为准。
- 如上游未返回用量数据，则按本平台估算用量计费。

### 2.2 价格调整

- 我们可能根据上游服务提供商的价格调整、运营成本变化等因素调整模型价格。
- 价格调整将在平台上提前公告，公告期满后生效。
- 价格调整前已充值的余额不受影响。

### 2.3 费用计算

- 费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价
- 费用以人民币（CNY）计价，精确到小数点后 6 位。
- 每次请求完成后实时扣费，余额不足时请求将被拒绝。

## 3. 余额管理

### 3.1 余额查询

- 您可随时在"账单"页面查看当前余额和消费明细。
- 余额更新可能有短暂延迟，以系统实际记录为准。

### 3.2 余额有效期

- 充值余额**无有效期限制**，不会过期失效。
- 但如账户连续 **12 个月** 未有任何登录或使用记录，我们有权冻结该账户。

### 3.3 余额转让

- 账户余额**不可转让**给其他用户账户。
- 邀请奖励余额可通过"邀请码"页面转入账户余额。

## 4. 退款政策

### 4.1 一般规则

**充值余额一般情况下不支持退款。** 原因如下：
- 充值金额已用于平台资源预留和服务保障
- 预付费模式下退款涉及渠道手续费等成本
- 余额无有效期限制，您可随时继续使用

### 4.2 可退款情形

以下情形可申请退款：
1. **服务终止**：因我们原因终止服务，退还扣除已消费金额后的剩余余额
2. **不可抗力**：因法律政策变化、上游服务终止等不可抗力导致服务无法继续
3. **我们主动终止**：我们基于自身经营需要或风险评估决定终止向您提供服务
4. **法律要求**：法律法规有强制性退款规定的

### 4.3 退款计算

- 退款金额 = 充值余额 - 已消费金额 - 渠道手续费
- 渠道手续费按支付渠道实际收取费率计算
- 退款将在审核通过后 **7-15 个工作日** 内原路退回

### 4.4 退款申请

- 请通过 support@example.com 提交退款申请
- 需提供账户信息、充值记录和退款原因
- 我们将在 **5 个工作日** 内审核并回复

## 5. 兑换码

### 5.1 兑换码使用

- 兑换码可在充值页面输入并兑换为账户余额
- 每个兑换码仅可使用一次，使用后即失效
- 兑换码有有效期限制，过期无法使用

### 5.2 兑换码限制

- 兑换码**不可转让、不可兑换现金、不可退款**
- 因用户原因导致兑换码失效的，不予补发
- 严禁买卖兑换码，违者账户将被冻结

## 6. 发票

### 6.1 发票开具

- 我们支持为充值金额开具增值税电子普通发票
- 发票金额以实际充值金额为准，不含赠送金额
- 发票申请请在充值后 **30 天内** 提出

### 6.2 发票信息

- 请在"发票管理"页面填写开票信息
- 发票信息一经确认，如需修改请联系客服
- 发票将在申请后 **5 个工作日** 内开具

## 7. 异常处理

### 7.1 充值异常

- 如充值后余额未到账，请保留支付凭证并联系客服
- 我们将在核实后 **1 个工作日** 内处理
- 因支付渠道原因导致的延迟，到账时间以渠道实际处理时间为准

### 7.2 计费争议

- 如对计费有异议，请在消费后 **7 天内** 提出申诉
- 申诉需提供请求时间、模型名称和争议金额
- 我们将在 **3 个工作日** 内核实并回复

### 7.3 重复扣费

- 如因系统故障导致重复扣费，我们将在核实后自动退还多扣金额
- 无需您主动申请，系统会自动检测并处理

## 8. 合规声明

- 本平台充值与支付服务遵守中华人民共和国相关法律法规
- 我们不会以任何形式挪用用户充值资金
- 所有交易记录保留 **7 年** 以备审计
- 我们配合监管机构的合法调查和取证要求

## 9. 条款变更

我们可能根据需要不时更新本条款。更新后的条款将在充值页面公示，继续使用充值服务即视为接受更新后的条款。
