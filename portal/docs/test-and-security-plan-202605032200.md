## 四、任务 3：安全漏洞测试计划

### 4.1 测试范围

```
┌─────────────────────────────────────────────────────────┐
│                    安全测试矩阵                          │
├──────────────┬──────────────┬───────────────────────────┤
│   认证安全    │   授权安全    │      数据安全             │
├──────────────┼──────────────┼───────────────────────────┤
│ • JWT 破解   │ • 越权访问    │ • SQL 注入               │
│ • 密码爆破   │ • 角色提升    │ • XSS 攻击               │
│ • Token 泄露 │ • IDOR       │ • 敏感数据泄露            │
│ • 会话固定   │ • API 滥用    │ • CSRF                   │
├──────────────┼──────────────┼───────────────────────────┤
│   输入验证    │   配置安全    │      基础设施安全         │
├──────────────┼──────────────┼───────────────────────────┤
│ • 边界输入   │ • 默认密码    │ • Docker 安全             │
│ • 特殊字符   │ • 环境变量    │ • 端口暴露                │
│ • 文件上传   │ • CORS 配置   │ • 日志泄露                │
│ • 请求大小   │ • HTTPS      │ • 依赖漏洞                │
└──────────────┴──────────────┴───────────────────────────┘
```

### 4.2 具体测试用例

#### A. 认证安全

| # | 测试项 | 方法 | 预期 |
|---|--------|------|------|
| A1 | JWT 弱密钥 | 尝试弱密钥签名 | 拒绝 < 32 字符 |
| A2 | JWT 过期 Token | 使用过期 Token | 返回 401 |
| A3 | JWT 篡改 | 修改 payload | 返回 401 |
| A4 | 密码爆破 | 连续错误登录 | 触发限流 |
| A5 | 验证码爆破 | 连续错误验证码 | 触发限流 |
| A6 | Token 续期 | 长时间使用 | 正常续期或过期 |

#### B. 授权安全

| # | 测试项 | 方法 | 预期 |
|---|--------|------|------|
| B1 | 水平越权 | 访问其他用户资源 | 返回 403/404 |
| B2 | 垂直越权 | 普通用户访问 admin | 返回 403 |
| B3 | IDOR | 遍历 ID 访问 | 返回 403/404 |
| B4 | 角色提升 | 修改自己角色 | 失败 |
| B5 | API Key 滥用 | 超出限额 | 限流或拒绝 |

#### C. 输入安全

| # | 测试项 | 方法 | 预期 |
|---|--------|------|------|
| C1 | SQL 注入 | 输入 `' OR 1=1 --` | 安全处理 |
| C2 | XSS | 输入 `<script>alert(1)</script>` | 转义或拒绝 |
| C3 | 路径遍历 | 输入 `../../etc/passwd` | 拒绝 |
| C4 | 超长输入 | 输入 10MB 字符串 | 限制大小 |
| C5 | 空字节 | 输入 `%00` | 安全处理 |
| C6 | JSON 注入 | 嵌套 JSON | 安全处理 |

#### D. 数据安全

| # | 测试项 | 方法 | 预期 |
|---|--------|------|------|
| D1 | 密码存储 | 检查数据库 | bcrypt hash |
| D2 | API Key 存储 | 检查数据库 | hash 存储 |
| D3 | 敏感信息泄露 | 检查 API 响应 | 无密码/hash |
| D4 | 日志泄露 | 检查日志输出 | 无敏感信息 |
| D5 | 错误信息 | 触发错误 | 不暴露内部细节 |

#### E. 配置安全

| # | 测试项 | 方法 | 预期 |
|---|--------|------|------|
| E1 | 默认密码 | 尝试默认密码 | 必须修改 |
| E2 | CORS | 跨域请求 | 限制域名 |
| E3 | 端口暴露 | 扫描端口 | 仅必要端口 |
| E4 | HTTPS | HTTP 请求 | 重定向或拒绝 |
| E5 | Rate Limiting | 高频请求 | 触发限流 |
