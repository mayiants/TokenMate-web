## Re-check Results — 2026-06-08

> 使用新增脚本 `scripts/check_i18n.py` 对全量模板进行复查，发现上一轮（19:00 audit）之后仍有遗漏。

### 新增发现

| 类别 | 数量 | 详情 |
|------|------|------|
| `{{t}}` 模板键缺失 | **0** | ✅ 完全修复 |
| `_t(...)` JS 键缺失 | **101** | ❌ 大量遗漏，集中在 `admin-models-general.html` (~60)、`admin-announcements.html` (~15)、`redemption.html` (~10)、`admin-keypool.html` / `admin-upstream-usage.html` / `admin-redemption.html` (若干) |

| `en.json` 含中文 | 0 | ✅ |
| Orphaned keys | 950 | 历史遗留编号键，不阻塞运行 |

### 重点缺失文件

| 文件 | 缺失键数 | 典型缺失示例 |
|------|----------|-------------|
| `admin-models-general.html` | ~60 | `Add Models`, `Delete`, `Sync Keys`, `Pause model`, `Restore model`, `Discontinue? Irreversible.`, `Added`, `Retry`, `Loading...` 等 |
| `admin-announcements.html` | ~15 | `信息`, `维护`, `警告`, `发布`, `已发布`, `草稿`, `已归档`, `归档`, `是`, `否`, `确定删除此公告？` 等 |
| `redemption.html` | ~10 | `兑换中...`, `关闭`, `请输入兑换码`, `Token Plan`, `Code Plan` 等 |
| `admin-keypool.html` | 1 | `请输入操作密码以导出密钥：` |
| `admin-upstream-usage.html` / `admin-redemption.html` | 2 | 分页碎片：`共 `, ` 条，第 `, ` / `, ` 页` |

### 根因分析

1. **`admin-models-general.html` 近期经历 drawer-first 重构**，inline JS 大量增加，但同步到 `window._i18nMessages` 的工作未跟上。
2. **部分页面（announcements、redemption）本身较旧**，此前只修复了 `{{t}}` 模板键，JS 侧 `_t()` 调用被忽略。
3. **分页碎片翻译模式**（`_t('共 ')+total+_t(' 条...')`）导致 key 数量膨胀，维护成本高。

### 建议修复策略

**暂不立即修复**（用户指示："i18n暂不修复，还有一些页面需要整合"）。待页面整合完成后，统一：
1. 将上述 101 个缺失键一次性补入 `layout.html` 的 `window._i18nMessages`。
2. 对 `admin-announcements.html`、`redemption.html` 等中文硬编码页面优先处理（它们在 English 模式下会直接显示中文）。
3. 考虑将分页碎片改为模板字符串插值（如 `_t('pagination_info', total, current, pages)`），减少碎片化 key。
