## 一、计费与定价

### Q1: Economy 折扣率 ✅

**确认**：
- Economy 是"用户组"概念，admin 可创建多个 eco 组（eco-1, eco-2...）
- 每个 eco 组包含不同模型，折扣率由 admin 创建时确定
- **编码默认：85 折（0.85）**
- eco 组服务质量较低（如 30rpm vs general 的 60rpm）
- 用户可自由切换 eco 组或回到 general 状态

### Q2: Code Plan / Token Plan 默认配置 ✅

**确认**：
- 默认只放一组，其他档位由 admin 自行创建
- **默认 Code Plan = ¥39/月 Lite 套餐**
  - rpm/rph/rp5h/rpw/rpmonth = 60/500/1200/9000/18000
- **默认 Token Plan = ¥39/月 Lite 套餐**
  - 60M token/月
  - 每日限制 = 每月额度的 20%

### Q3: 支付货币 ✅

**确认**：
- 支付宝/微信：**默认 RMB**，但建议有 RMB 和 USD 可选
- Stripe/PayPal：**默认 USD**，允许客户选择其他币种（如果接口支持），否则只用 USD

### Q4: 余额精度 ✅

**确认**：
- 支持到小数点后 2 位（cents 精度）
- 默认显示 RMB
- 用户 Dashboard 可选择默认币种（RMB / USD）

### Q5: 企业用户额度设置 ✅

**确认**：
- 企业 quota 上限由 admin 分配时设定，可由 admin 修改
- 一般设置为约定额度的 **110%**
- 创建企业时设置：名称、联系人、quota 额度、**服务中止 quota**、允许 model
- 发送 enterprise_admin 邮箱邀请
- 一个公司最多 **3 个管理员**，权限一致
- **强制检查同一公司使用同一企业域名邮箱**
- 自然月月结，不满一个月按实际天数计费出账单

## 四、权限与安全

### Q18: super_admin 降级流程 ✅

**确认**（详细流程）：
1. 只有 1 位 super_admin 时**无法自己降级**
2. 负责管理的 super_admin 在管理页面**申请降级**另一位
3. 申请邮件发给**所有 super_admin**
4. 被降级的 super_admin 登录系统点击**同意** → 立即降级
5. 如果被降级的 super_admin 因意外无法处理邮件或登录：
   - **5 个工作日后**，账户被冻结（deactive）
   - 管理 super_admin 可以**创建另一个 super_admin 账户**
6. 被降级的 super_admin 成为 **system_admin**
   - 不占用 system_admin 名额
   - 可作为 system_admin 继续工作，也可被 super_admin 删除
7. 安全措施：
   - 被降级账户锁定后**无法使用也不能删除**
   - **必须保留至少 1 年**
   - 防止恶意降级

### Q19: 密码策略 ✅

**确认**：
- 至少 **8 位**
- 必须包含：**大写 + 小写 + 数字 + 特殊字符**（各至少一个）
- 密码输入框内有提示（参考 Node.js 登录时密码框的实现）
- **5 分钟内连续失败 5 次 → 锁定 30 分钟**

### Q20: 会话超时 ✅

**确认**：
- JWT access token：**1 小时**
- Refresh token：**7 天**
- 关闭浏览器后：不建议保持，需要重新登录
- Remember me：如果容易实现，建议 **24 小时内**可以保持
