数据驻留

您的数据存储在新加坡及亚太地区的云服务器上，符合新加坡个人数据保护法 (PDPA) 的要求。我们不会使用您的数据训练任何 AI 模型。

我们收集的信息

我们坚持最小必要原则，仅收集提供服务所需的信息：注册邮箱、账户名称、API 使用数据。我们不会收集不必要的个人信息。

信息用途

您的信息仅用于：提供和改善服务、计费和用量统计、安全防护和反滥用。我们绝不将您的 API 业务数据用于模型训练或其他商业目的。

数据安全

我们采用行业领先的加密技术（AES-256）和安全措施保护您的数据。API Key 加密存储，传输全程 TLS 加密，审计日志保留 7 年。

数据跨境传输

为提供 AI API 中转服务，您的 API 请求内容可能被传输至位于其他国家/地区的上游 AI 服务提供商。我们确保此类传输符合新加坡 PDPA 关于跨境数据传输的相关规定。

您的权利

根据新加坡 PDPA，您可以随时：查看和导出您的个人数据、要求更正不准确的数据、要求删除您的账户和数据、撤回对数据收集的同意。如有疑问请联系 support@woodgit.com。
