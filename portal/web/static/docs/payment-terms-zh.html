重要提示

  • 请确保您的账户有足够资金进行交易。
  • 若充值过程遇到交易问题，请前往相应的第三方支付平台进行确认。
  • 为了保障您的账户安全与充值体验的顺畅，您每月最多可以享受30次充值服务。1天内未支付的订单，会自动关闭。
  • 充值完成后，您可以前往账户总览页面查看账户余额。

一、充值性质

本平台采用预充值消费模式，您需要预先充值到账户余额后方可使用 API 服务。充值金额将计入您的账户余额，用于抵扣 API 调用产生的费用。账户余额以美元 (USD) 为计价单位，仅可用于本平台 API 服务消费，不具有现金价值。

二、计费方式

本平台按 Token 用量计费，根据不同模型和请求类型（输入/输出）分别计价。每次请求的 Token 用量以上游服务提供商返回的用量数据为准。费用 = 输入 Token 数 × 输入单价 + 输出 Token 数 × 输出单价。每次请求完成后实时扣费，余额不足时请求将被拒绝。

三、余额管理

充值余额没有有效期，不会过期失效。但如账户连续 12 个月未有任何登录或使用记录，我们有权冻结该账户。账户余额不可转让给其他用户账户。

四、退款政策

充值余额一般不支持退款。符合以下情形可申请退款：

  • 因我们原因终止服务，退还扣除已消费金额后的剩余余额。
  • 因法律政策变化、上游服务终止等不可抗力导致服务无法继续。
  • 我们基于自身业务需要或风险评估决定终止服务。
  • 适用法律有强制性退款规定。

退款金额 = 充值余额 - 已消费金额 - 渠道手续费。退款将在审核通过后 7-15 个工作日内原路退回。

五、兑换码

兑换码可在充值页面输入并兑换为账户余额。每个兑换码仅可使用一次，使用后即失效。兑换码不可转让、不可兑换现金、不可退款。严禁买卖兑换码，违者账户将被冻结。

六、异常处理

如充值后余额未到账，请保留支付凭证并联系客服，我们将在 1 个工作日内处理。如对计费有异议，请在消费后 7 天内提出申诉。因系统故障导致重复扣费的，我们将在核实后自动退还多扣金额。

七、合规声明

本平台由在新加坡注册的公司运营，充值与支付服务遵守新加坡共和国及服务所在地区适用的法律法规。我们不会以任何形式挪用用户充值资金。所有交易记录保留 7 年以备审计。

八、发票政策

发票申请提交后由管理员人工审核开具，处理时间约 1-3 个工作日。
